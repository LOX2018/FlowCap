# 封装测试版 · 打包说明

本版已**取消脚本启动制**：不再依赖 `python -m` 或双击 `.bat`，而是打包成单个可执行文件，
双击 `DYAutoDM.exe` 即启动控制台；守护进程由 GUI 内部自动拉起（用 exe 自身 + `--mode` 参数）。

## 本机限制
当前开发机 `python/pythonw` 是 Microsoft Store 占位符，**无法真正运行或打包**。
请在一台装有**真实 Python 3.10+** 的机器上执行下列步骤。

## 一键打包
```bash
cd DY_Spider_base
pip install pyinstaller
python build_exe.py
```

## 产物
```
dist/DYAutoDM/
├── DYAutoDM.exe        # 统一入口（GUI / 守护 / 接收）
├── vb_chromium/        # 浏览器内核（随附，不进 exe）
├── vb_profile_default/ # 浏览器 profile
├── vb_profile_dm/
├── pw_profile_dm/
├── .env                # 凭证（测试机首次扫码生成）
└── logs/
```

## 运行方式（测试人员）
直接双击 `DYAutoDM.exe`：
- 默认启动 GUI 控制台；
- 点「🚀 启动守护」会自动用 `DYAutoDM.exe --mode daemon` 拉起无窗口浏览器守护；
- 点「📥 启动接收守护」会自动用 `DYAutoDM.exe --mode recv` 拉起无窗口接收守护。

命令行（可选，调试用）：
```bash
DYAutoDM.exe --mode gui      # 控制台（默认）
DYAutoDM.exe --mode daemon   # 浏览器守护
DYAutoDM.exe --mode recv     # 接收守护
```

## 旧 .bat 文件
`启动GUI.bat` / `启动守护.bat` / `启动接收守护.bat` / `启动命令行.bat` 保留作**开发调试用**，
正式测试版请使用封装 exe，无需这些脚本。

## 注意
- 打包前确保 `requirements.txt` 依赖已安装（aiohttp/websockets/pycryptodome 等）。
- 浏览器内核 `vb_chromium` 体积较大，打包后整体目录约数百 MB，属正常。
- 首次运行需在某账号下扫码登录，凭证写入 `.env`，守护负责保活。
