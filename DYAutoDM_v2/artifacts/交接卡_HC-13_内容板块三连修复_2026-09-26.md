## 1. 已完成（逐条带证据）

### ① secsdk 签名断链修复（v0.45.8，提交 `6971412`）
- **根因**：5 个内容列表端点（`favorite`/`post`/`listcollection`/`mix/listcollection`/`collects/list`）
  在 `utils/secsdk_web_sign.PROTECTED_PATHS_GET` 保护清单内，但调用点**未接 `signed_url()`**
  → 裸 `params.get()` 缺 uifid/签名 → Argus 网关恒返 **403**（46B `Blocked by ArgusSecurityPlugin Uifid Not Found`）。
- **改动**：`dy_apis/client_user.py`（`get_user_work_info`/`get_user_favorite`）、
  `dy_apis/client_collection.py`（4 处）改走 `params.signed_url()`；
  `get_my_sec_uid` 加进程内缓存+退避重试；`douyin_api.py` 加 `_sec_uid_cache`。
- **证据**：实机 403 → **200**；`.known-gaps.json` 删除 5 条已修缺口；`check_contracts.py` G2 复 PASS。

### ② 关注假入口去除（同提交）
- **根因**：基座 `dy_apis` **无关注写方法**（`commit_follow`/`follow_user` 均不存在，只有读接口）
  → `POST /action/follow` 恒 501；前端 `platform.ts` 有定义但**页面无调用**。
- **改动**：删除端点 + `FollowReq` 模型 + 前端 `follow()` 定义。
- **证据**：部署版 `/openapi.json` 平台端点 **20 条、无 follow**。

### ③ 视频无法播放根因修复（v0.45.9，提交 `16c250c`）
- **根因**：`<video src>` **无法携带 `X-Member-Token`**，而 `/api/platform/media/stream`
  受 `main.py` 会员中间件保护 → 裸地址**必然 401**。
  （实测：裸请求=401；带 token+Range=**206 `video/mp4` + `ftyp` 有效**）
- **关键排除**（避免误修）：
  - 编码正常：`play_addr`=**H.264/AVC + AAC**，`_265`=H.265/HEVC，均标准 MP4（`ftypisom`）。
  - 「CDN 直链必 403」是**错前提**：实测仅 UA→403，**UA+Referer**→200/206。
  - **webview 无法直连 CDN**：Referer 白名单 —— `Referer=douyin.com`→206；
    `tauri://localhost`→403；`http://localhost:8000`→403（浏览器禁止 JS 伪造 Referer）。
- **改动**：`frontend/src/components/player/player-media-stage.tsx` 接入既有
  `useAuthedMediaUrl`（本地受保护地址带 token fetch→Blob；**后端零改动**，不动 `_MEMBER_EXEMPT`）。
- **证据**：部署版端到端 `stream-ticket`(200) → `stream` 带 token **206 + 131072B + ftyp 有效**；
  无 token 对照 **401**。
