## 4. 🔴 本会话踩坑留痕（避免重蹈）

| # | 坑 | 判据 / 定式 |
|---|---|---|
| 1 | **降级 camoufox 造成版本矩阵破裂** | 我执行 `pip install camoufox==0.5.5` 时**连带把 playwright 降到 1.60.0**，跳出「camoufox 0.5.6 + playwright 1.62.x」这套**已实测可用**的组合。**根因链**：camoufox 源码 `__version__.py` 内 `PLAYWRIGHT_BROWSER_FLOORS = (((1,61),'beta.30'),)` —— playwright ≥1.61 必须配浏览器 **beta.30**（beta.29 会在 `new_context()` 抛 `Protocol error (Browser.setDefaultViewport)`）。**定式：动 camoufox/playwright 版本前先读该 floor 表；改完必须复核两包版本 + 浏览器 beta 号三者匹配。** |
| 2 | **`camoufox fetch` 依赖 `official/stable` 这一层** | 手动把 beta.30 解压进 `Cache/browsers/official/152.0.4-beta.30` **不够** —— camoufox 找的是 `official/stable`。手动拼缓存目录**不可取**；正确做法是让 `camoufox fetch` 自己装。 |
| 3 | **别用「有头窗口」当诊断锚** | 本会话曾被 `-foreground` flag 误导到「Session 0 隔离 / 需改代码脱离服务会话」——**实际是版本矩阵破裂**。**定式：BCC-070 / 启动失败先查「包版本 ↔ 浏览器 beta」是否匹配，再怀疑会话隔离。** |
| 4 | **我的过度声明被用户两次纠正** | ① 把 `/api/messages/send`（`source="manual"` 旁路）当成 H-2 全链路达成 → 被 `dm_uid_sink` **零新增**反证；② 把「房间已下播」当成事实 → 实为 ENG-023 误判。**定式：判据必须落在**全链路的那一段**，且有 DB/日志硬证据；旁路验证只能证明旁路。** |
| 5 | **curl 传中文参数会乱码** | `curl --data-urlencode "acct=中文"` 在 MSYS bash 下变 `�н�����`。**定式：带中文的 API 调用一律用 Python `requests`（`params=`/`json=`），不要用 curl 拼中文。** |
| 6 | **`stop`/`start` 同秒竞态会把新任务硬停** | 收尾脚本里调 `engine/stop` 会打到刚起的任务（`ENG-012 引擎硬停止` + `SENT-002 清空队列`）。**定式：起任务与停任务的脚本分开；收尾停引擎要么显式 `acct`，要么另起一次调用。** |
| 7 | **多引擎实例会互相污染状态** | 并行起两个账号任务时 `/api/tasks/current` 只显示一个，日志里两个房间的 `room_status` 交替出现 → 误判。**定式：`/api/engine/accounts` 逐账号核对；`/api/engine/stop` 必须带 `acct`（是 **query 参数**，不是 body —— 塞 body 会被忽略并返 409）。** |
