# DYAutoDM wp 私信通道接入方案

**Goal:** 在私信中心接入「抖音网页版（wp）」通道接收/发送消息,与现有 WS 通道并存。

**Architecture:**
- 接收: BCC 已在 `douyin.com/chat?isPopup=1` 常驻浏览器,在现有 `CAP_USERINFO_HOOK_JS` 旁**新增私信消息 hook**,截 `get_message_by_init` 响应 + WebSocket 推送,解析后写入 SQLite dm_messages(标记 `source='wp'`)
- 发送: 在 `recv_daemon` 旁**新增 wp send 路径**,通过 `exec_js` 在 chat 页内调用抖音前端 `DYG-IM` SDK 发送接口(同域、有 cookie)
- 前端: 私信中心 `RawMessage` 加 `source` 字段,UI 显示角标「网页」/「WS」区分通道;过滤/滚动逻辑不变
- 双通道去重: 同一 `conv_id` + `client_msg_id` 在 SQLite 上 `UNIQUE` 约束,WS 已落库的消息 wp 不会重复

**Tech Stack:** Playwright (BCC)、FastAPI、SQLite WAL、Fetch/XHR hook、protobuf 解析(已有 `conversation_capture.parse_init_protobuf` 可复用)

```python
CAP_WP_MESSAGE_HOOK_JS = r"""
(() => {
  if (window.__CAP_WP_MESSAGE__) return 'already';
  window.__CAP_WP_MESSAGE__ = { events: [] };
  const push = (kind, url, body) => {
    try { window.__CAP_WP_MESSAGE__.events.push({ kind, url, body, ts: Date.now() }); } catch(e) {}
  };
  // fetch hook
  const origFetch = window.fetch.bind(window);
  window.fetch = function(u, o) {
    const p = origFetch(u, o);
    try {
      const url = (typeof u === 'string') ? u : (u && u.url) || '';
      if (/im\/(notice\/)?get_message_by_init|web\/im\/conversation/.test(url)) {
        p.then(r => r.clone().text().catch(()=>null)).then(t => {
          if (t) push('http', url, t.slice(0, 200000));  // 限 200KB 防爆
        }).catch(()=>{});
      }
    } catch(e) {}
    return p;
  };
  // WebSocket hook (send + message 双向)
  const OrigWS = window.WebSocket;
  window.WebSocket = function(u, p) {
    const ws = p ? new OrigWS(u, p) : new OrigWS(u);
    const origAdd = ws.addEventListener.bind(ws);
    ws.addEventListener = function(ev, cb) {
      if (ev === 'message') {
        return origAdd(ev, (e) => {
          push('ws', String(u), (typeof e.data === 'string' ? e.data : '<binary>').slice(0, 200000));
          return cb(e);
        });
      }
      return origAdd(ev, cb);
    };
    return ws;
  };
  return 'captured';
})()
"""
```

```python
async def capture_wp_messages(self) -> list[dict]:
    """读取 BCC hook 截到的 wp 私信事件,读后清空。"""
    async def _do():
        if "/chat" not in (self._page.url or ""):
            await self._page.goto("https://www.douyin.com/chat?isPopup=1",
                                  wait_until="domcontentloaded", timeout=25000)
            await self._page.wait_for_timeout(2000)
        try:
            evs = await self._page.evaluate(
                "() => window.__CAP_WP_MESSAGE__ ? window.__CAP_WP_MESSAGE__.events : []")
            await self._page.evaluate(
                "() => { if (window.__CAP_WP_MESSAGE__) window.__CAP_WP_MESSAGE__.events = []; }")
        except Exception as e:
            logger.warning(f"[bcc] 读 wp message 失败: {e}")
            return []
        return evs or []
    return await self._exec(_do)
```

```python
# coding=utf-8
"""WP 通道私信接收循环。

从 BCC /wp_messages 拉取 hook 截到的事件,解析 protobuf/JSON,写入 SQLite。
去重键: (account, conv_id, client_msg_id) UNIQUE 约束,WS 已落库的不重复写。
"""
import asyncio
import time
from loguru import logger
from auto_dm import accounts as acc
from auto_dm.conversation_capture import parse_init_protobuf

POLL_INTERVAL = 3  # 秒


async def poll_once(client, account: str) -> int:
    """拉一次并入库,返回新增条数。"""
    import httpx
    port = acc.recv_daemon_port(account) + 1000  # BCC 端口 = recv_daemon + 1000
    try:
        async with httpx.AsyncClient(timeout=10) as cli:
            r = await cli.post(f"http://127.0.0.1:{port}/wp_messages", json={})
        if r.status_code != 200 or not r.json().get("ok"):
            return 0
        events = r.json().get("events") or []
    except Exception as e:
        logger.debug(f"[wp_recv] 拉取失败: {e}")
        return 0
    n = 0
    for ev in events:
        # TODO: 解析 protobuf/JSON,落 dm_messages
        # 占位:仅打日志,待 Task 4 完善
        logger.info(f"[wp_recv] 收到事件: kind={ev.get('kind')} url={ev.get('url')[:60]}")
    return n


async def run_wp_recv_loop(account: str):
    """长跑循环,异常自动重连。"""
    logger.info(f"[wp_recv][{account}] 启动轮询")
    while True:
        try:
            await poll_once(None, account)
        except Exception as e:
            logger.warning(f"[wp_recv][{account}] 轮询异常: {e}")
        await asyncio.sleep(POLL_INTERVAL)
```

```python
    """在 chat 页上下文里调用抖音前端 IM SDK 发文本私信。"""

      const candidates = [

        () => window.DY_IM?.sendText?.({{conversation_id: {json.dumps(conv_id)}, text: {json.dumps(text)}}}),

          const r = await c();
```

## 风险与开放问题

| 风险 | 缓解 |
|---|---|
| **IM SDK 调用方未实测**(Task 6.5) | 先列 console 全局变量,再试 send |
| **WebSocket 帧格式与 WS 通道不同** | Task 4 解析器先宽进,失败落 extra |
| **去重 UNIQUE 索引可能与现有 schema 冲突** | 加 WHERE 子句,只对有 client_msg_id 的约束 |
| **昵称红线**: wp 通道不要触发额外 API | hook 纯被动,不解出 sec_uid 主动查(08 §13) |
| **双通道消息顺序**: wp 比 ws 慢,UI 显示错位 | 用 ts 排序,前端不依赖入顺序 |
| **BCC 浏览器被人关闭**: wp 通道全断 | Task 5 启动逻辑检测 BCC 心跳,断时降级仅 WS |
