## 使用规则

1. **契约先于代码**：改动某模块前先读对应契约；若需改契约语义 → 属**架构变更**，须先改契约文件（变更控制门），再改代码。
2. **契约即判据**：每份契约 §「验证方式」的命令必须可复跑，且应进 CI / 门禁脚本。
3. **单源真值（SSOT）**：同一语义**只在本目录定义一次**；`工作记忆/` 与 `05_端点与协议台账.md` 仅作**引用**，不复制契约内容。
4. **新增契约**：业务域新增 or 旧模块补契约时，命名 `C-NN-<kebab-topic>.md` 并登记到本表。
