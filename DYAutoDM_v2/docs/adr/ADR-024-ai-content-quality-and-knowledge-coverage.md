# ADR-024：AI 内容层质量 —— 知识覆盖（陈旧性骨折）+ 残句/断言护栏

- 状态：已采纳（2026-09-28，v0.45.76）
- 关联：`services/ai_reply.py`、`services/pro_kb.py`（数据）、`frontend/src/components/settings/AiEngineSection.tsx`
- 上游依据：`skill llm-feature-debugging` 零号判据（先怀疑喂给模型的东西，不先改 prompt）
- 承接：ADR-021 D4（AI 获客治「客服腔」）—— 本 ADR 是其**专业正确性**延伸

## 背景

用户实测：问「陈旧性骨折还能认工伤吗，厂里不认」，AI 回 **「能认」**。
用户判定：**与专业知识完全相悖** —— 陈旧性骨折难以证明是本次事故造成，
实务中**基本不予认定**；等级也按治疗后功能障碍评，不得凭伤情断言。

## 实测取证（Step 1~3，真机载荷 + 库快照）

- `pro_kb` 共 **6 条**：全部是赔偿项目/等级月数/户口/合同，
  **无一条**讲「陈旧性骨折能否认定」⇒ 模型无事实可锚（不是 prompt 问题）。
- `validate_reply` 只有**违禁词 + 最大长度**，**无最小长度** ⇒ 2 字残句直发。
- `_generate_reply` 优先级链：`reply_kb.find_match`（命中即回，零 token）→ AI（rag 注入 pro_kb）→ 兜底。
  命中库 81 条全为 `auto` 学习条目（40 条仍可生效），是内容质量另一风险面（见「未覆盖」）。
- 降级链实测：`agnes-2.5-flash` 两次 60s 超时 → 切 `deepseek-v4.1-flash` → 只回「能认」。

## 决策

### D1 补知识（**根因修复**）

向 pro_kb 增 **2 条 grounded 专业条目**（经**运行中后端 API** 写入 —— 活库被后端持有，
遵守并发写铁律，不直写库）：
1. 【工伤认定疑难点 / 陈旧性骨折】——**基本不予认定**；须补事故证明+首诊记录+时间线；
   即便认定一般也**评不上等级**（看功能障碍）；**不得对客户承诺结果**。
2. 【劳动能力鉴定 / 评残依据】——等级按**功能障碍**（GB/T 16180）评，
   **不按损伤名称对号入座**；不得凭伤情断言「就是几级」。
   依据：《工伤保险条例》第 14/17/21/22 条。

### D2 残句护栏

`validate_reply` 增 `min_reply_len`（配置项，默认 **5**，与 prompt「5-40 字」口径一致）。
低于阈值判残句 → 走兜底话术（绝不外发半截话）。

### D3 专业准确性护栏

`validate_reply` 增**绝对化断言**拦截（`_RE_ASSERTIVE`）：命中即走兜底。
- 「陈旧性骨折/旧伤 + 肯定认定」（任一方向）
- 等级断言（「能评上九级」「确定就是十级」）

**边界（防误伤）**：只拦「把话说死」的形态；含「最终以认定结论为准」的正常专业分析
**不命中**（已用正控用例固化）。

## 后果

- 正向：陈旧性骨折这类问题回到**与专业知识一致**的口径；残句不再外发；断言被拦。
- 权衡：D3 是**形态护栏**，拦不住「措辞含糊但内容正确偏保守」的错误（见未覆盖）。
- 配置：`min_reply_len` 进 AI 页（与 `max_reply_len` 并列），可调。

## 验证（真机）

| 问题 | 修复前 | 修复后 |
|---|---|---|
| 陈旧性骨折还能认工伤吗 | 「**能认**」 | 「旧伤基本认不了，关键看是不是这次干活受的伤」 |
| 我腰椎骨折能定几级 | 「多评九级」 | 「几级**不看骨折名字**，看压缩程度和后期功能恢复，以鉴定为准」 |

门禁：`test_ai_reply_quality_guards` **6/6**（4 负控 + 2 正控）·
`test_h31_ai_reply_safety` 9/9 · `test_reply_purify*` 全绿 · 前端 `npm run build` ✓。

## 未覆盖（诚实标注）

1. **`sem_enabled=False`** ⇒ pro_kb 注入走「时间衰减取前 5」而**非相关性检索**；
   实测出现「十级能赔多少 → 没法一口报」（KB 有「十级 7 个月」却答含糊）。
   ⇒ 建议开启语义检索（`ai_sem` 链 + `sem_model`），**需用户定夺**。
2. **命中库 81 条 auto 碎片**（40 条仍生效）仍是「命中即回」最高优先级风险面；
   治理路径见 ADR-022（提纯门），存量清理**需用户拍板**。
3. 断言护栏是**形态匹配**，非知识推理；覆盖有限，属「防绊」非「根治」。
