## 一、结论汇总（每条附证据）

### 1. 接口方案（纯 HTTP，无浏览器）：**不通**

| 尝试 | 结果 | 探针 |
|---|---|---|
| 匿名 msToken（裸请求 douyin.com）| ❌ 只拿到 `__ac_nonce`（JS 挑战 cookie），无 msToken | `probe_anon_mstoken.py` |

## 二、发现的代码缺陷

### DEFECT-1：`dyGenerateInitData` 违反单 profile 铁律（100% 失败）

**位置**：`backend/dy_apis/login_api.py:205`

```python
async def dyGenerateInitData(self, headless=True, cookie_str="", landing_url=...):
    _acc_name = None
    _pw, _browser, context, _backend = await launch_async(
        _vb_mode, _cfg, headless=headless, force=True, account=_acc_name)
        # ↑ 未传 user_data_dir → 被门禁拦截
```

**实测错误**：
```
[BCC-058] Camoufox 内核启动失败，且已按配置禁止回退 Chromium:
  [camoufox] 未指定固定 profile 目录。单 profile 铁律：禁止临时目录，
  必须传入 accounts.profile_dir_of(env_path)
```

**根因**：`vbrowser.py:825-834` 于 **2026-08-17 修订**铁律
（"`force=True` 仅表示不复用登录态，**仍使用同一固定 profile 目录**"），
但 `dyGenerateInitData` 未同步修订 ⇒ **契约漂移**。

**正确范式**（同文件 `login_api.py:276 login_grab_ticket` 已做对）：
```python
_acc_profile = _accounts.profile_dir_of(env_path)      # ✅
_acc_name = basename(dirname(abspath(env_path)))       # ✅
```

**附带问题**：`dyGenerateInitData` **无 `env_path` 参数**，其 2 个调用点
（`qrcodeMain:1387` / `phoneMain:1409`）也无账号参数 ⇒ 需同时改造。

## 六、M1 实施期新增实测（2026-09-26 13:2x~13:3x）

### 6.1 接口方案在"未登录"场景下**确认不可行**（铁证）

**探针**：`scratch/v_m1b.py`（复刻 `dyGenerateQRcode` 请求，保留原始响应）

**实测结果**：
```
前置：auth.cookie 39 项（含 ttwid ✅ / msToken ✅），但 web_protect ❌ / keys ❌（未登录）
请求：GET https://sso.douyin.com/get_qrcode/  （参数与 dyGenerateQRcode 逐项一致）
响应：HTTP 200，长度 10168，**Content-Type: text/html**
      body 含 <html> / <script> / captcha / verifyCenter / TTGCaptcha
      JSON 解析失败 → safe_json 降级为 None
```
**⇒ 判定**：未登录态调 `get_qrcode` 被**反爬挑战页**拦截（返回验证组件 HTML，非 JSON）
⇒ **接口方案在未登录场景下不可行**，**必须走 DOM 方案**（用户 2026-09-26 已定）。

### 6.2 修复 M1 时发现的两个**新缺陷**（均已修，取证如下）

**缺陷 A：`builder/auth.py:perepare_auth` 守卫挡不住 `None`**

```python
# 原实现
if web_protect_ != "":          # ← 挡得住 ""，挡不住 None
    web_protect_ = json.loads(json.loads(web_protect_)['data'])
```
**触发链**：
```
未登录账号 → security-sdk 未生成有效 web_protect → localStorage 读到 None
  → perepare_auth('', None, None) → `None != ""` 为真 → json.loads(None)
  → TypeError: the JSON object must be str, bytes or bytearray, not NoneType
```
**修法**：守卫改为 `if web_protect_ and isinstance(web_protect_, str)`，
`None` 分支记 DEBUG 日志并跳过（保留既有字段）。**有效路径行为逐字不变**。

**缺陷 B：`dyGenerateInitData` 拿到 None 不校验就下发**

```python
for _ in range(6):
    await asyncio.sleep(4)
    web_protect_str = await _read_page.evaluate('localStorage[...]')
    if keys_str and web_protect_str: break
auth.perepare_auth('', web_protect_str, keys_str)   # ← 可能是 None
```
**修法**：① 提升 `login_grab_ticket` 内的嵌套 `_web_protect_valid` 为**模块级
`is_web_protect_valid()`（SSOT）**；② 轮询直到**形态有效**（最长 40s）；
③ 无效时传**空串**（不传 None）；④ 新增 **`AUTH-062`** 如实告警（含"因该账号当前未登录"提示）。
