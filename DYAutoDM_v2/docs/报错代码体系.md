# 统一报错代码体系（Error Code）手册

> **每条 error/warning 日志都带 `[域-序号]` 代码前缀**（如 `[BCC-012]`），遇到报错先查码，不再翻代码/知识库全量搜索。
>
> 本手册由 `backend/errcode.py` 自动派生（2026-09-11 校准）：**312 个代码 / 18 个域**。
> 代码增删后请重新生成本表，避免手册与源码脱节。

## 用法

1. **看日志前缀**：`14:32:01 | ERROR | [BCC-012] [bcc] 保活探活 uid 漂移...`
2. **查码**（三选一）：
   - 接口：`GET /api/errcodes?domain=BCC`、`?q=漂移`（关键词匹配 meaning/cause/action，免登录）；单码 `GET /api/errcodes/BCC-012`
   - 本手册下方代码表
   - `backend/errcode.py` 的 `ERRCODES` 注册表（含 `file:line` 直接定位源码）
3. **按 cause/action 处置**：每域的常见原因与排查入口见下表。

## 新增报错日志的规范

```python
# 新报错必须申请新码：在 errcode.py 的 ERRCODES 追加（序号 = 域内最大序号 + 1），
# 然后日志调用带码：
logger.error("BCC-046", f"[bcc] 新增场景失败: {e}")
logger.warning("SEND-037", f"[send][{acct}] 限速: ...")
# 高频轮询路径禁止打 info（铁律 §七⑥）；可选 logger.debug
```
