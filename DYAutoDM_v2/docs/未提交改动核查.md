## 三、风险清单（按严重度排序）

### 🔴 高

1. **版本号跨 3 个 minor 累积未提交，提交历史将丢失版本粒度**
   - 现状：HEAD = `0.38.5`，工作区 = `0.41.1`。中间 `0.39.0`（模型中心 v2 + 链麦）、`0.40`（知识维护）、`0.41.0`（玻璃主题）全部压在同一次未提交状态。
   - 影响：无法用 `git log` 追溯「哪个版本引入了什么」，也无法按版本回滚单条业务线。
   - 证据：`git show HEAD:DYAutoDM_v2/package.json` → `0.38.5`；`git diff package.json` → `0.41.1`；`git log --oneline -8` 末条为 `d0b55f3 fix(member): …`。
   - 处置：见第四节建议分组（按业务线拆 6~8 次提交，版本号单独一次 "release" 提交）。

2. **`GlassButton.tsx` / `GlassSeg.tsx` / `GlassSwitch.tsx` 三个新组件无任何引用（未接线）**
   - 现状：全仓 grep 仅有 `TopNav.tsx:17 import ThemeSwitch`；三个玻璃控件**零 import**。
   - 影响：可能是「预留组件」也可能是「TopNav 内联写法替代后遗漏删除」。若为预留，属正常；若为遗漏，则是死代码，且会在后续 `noUnusedLocals` 清理中被误删。
   - 证据：`grep -rn "GlassButton|GlassSeg|GlassSwitch|ThemeSwitch" frontend/src --include=*.tsx` → 仅命中 TopNav→ThemeSwitch。
   - 处置：提交前向用户确认「是否保留」。建议保留并单独提交在主题 commit 内（组件文件不影响构建）。

3. **`frontend/src/pages/kb.tsx` 无对应主导航项，仅能从 AI 页卡片跳转**
   - 现状：`App.tsx:380 {tab === "kb" && <KbPage {...pageProps} />}`，但 `components/ui.tsx` 的 `TABS` 数组**无 `["kb", …]` 条目**，`TopNav` 又只遍历 `TABS` → 顶栏不会出现「知识库」tab。
   - 唯一入口：`ai.tsx:424 onClick={() => props.setTab?.("kb")}`。若 `props.setTab` 为空（该 prop 可选），入口也会静默失效。
