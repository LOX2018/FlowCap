### 1.2 流缓存（30 分钟，用户 2026-09-21 要求）

**文件**：`backend/api/platform.py`（`_cache_get` / `_cache_put` / `stream_cache_stats`）

实测证据：
```
第一次: HTTP 206 | X-Stream-Cache: MISS | bytes 1048576 | stats items=1
第二次: HTTP 206 | X-Stream-Cache: HIT  | bytes 1048576 | 耗时 4ms | 内容逐字节一致
不同Range: X-Stream-Cache: MISS（按 (url,range) 分键）
ttl_sec: 1800（= 30 分钟）
```
**设计取舍**：内存 LRU（64MB / 200 条上限），**不落盘** ——
单作品可达 400MB（实测 401,673,127 字节），落盘会撑爆磁盘。
只缓存 **带 Range 的小片段**（≤8MB）；无 Range 的整片保持边收边转，不读进内存。
