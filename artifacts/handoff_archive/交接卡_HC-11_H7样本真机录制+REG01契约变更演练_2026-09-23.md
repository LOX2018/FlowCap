### 2.1 🔴 H-7 样本① `cmd301_history` 录制

**前置（缺一不可）**：
1. 启动应用（`C:\temp\dyautodm_design`，走 `/quit` 优雅退出）；
2. 在**卡片页选中一个含图片的会话**（`skey` 非空 —— 长会话更佳，会触发 301 翻页）；
3. **启动前**设 `DY_REPLAY_RECORD_301=<临时目录>`（**注意**：环境变量对**已启动**的
   sidecar 不生效，须在启动应用前设好，或用能透传环境变量的启动方式）。

**产出 → 入库**：
```bash
cd DYAutoDM_v2/backend
PY="$LOCALAPPDATA/Programs/Python/Python314/python.exe"
# ① 录制（应用内触发该会话的历史拉取）
# ② 入库（manifest 必须有 expected{total_msgs, with_skey}）
PYTHONPATH=. "$PY" -m replay.recorder --from <录到的 .bin> --name cmd301_history \
   --desc "cmd301 长会话历史补全（含图片 skey）" \
   --provenance "2026-09-xx 实机录（账号 <X>；会话 <Y>）" \
   --account-uid <uid> --expect total_msgs=<N> --expect with_skey=<k>
```
**完成标准**：`manifest` 有 `expected{total_msgs, with_skey}` 且 `with_skey ≥ 1`；
对应回放用例**零 BCC 全绿**。
