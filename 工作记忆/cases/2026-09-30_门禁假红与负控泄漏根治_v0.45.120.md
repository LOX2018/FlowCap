## 五、🔴 本轮操作事故（必须记档）

**`git worktree remove --force` 跟随 junction 递归删除其目标** ⇒ 清空**主仓** `node_modules`（104 包）**并连带删除 `frontend/` 整个目录**（135 文件）。

- **成因**：为省 npm install 在 worktree 建 `node_modules` junction 指向主仓；Git 删工作树时**穿过链接**删了目标。
- **恢复**：① `git checkout HEAD -- DYAutoDM_v2/frontend/` 取回源码；② `git checkout HEAD -- package-lock.json`（`npm install` 曾把 267 条目改写成 13）；③ `rm -rf node_modules && npm ci --prefer-offline`（顺序反了会因状态缓存误判「up to date」而空装）。
- **判据**：删任何含 junction/symlink 的目录前，**先 `(Get-Item $p).LinkType -eq 'Junction'` → `$i.Delete()` 只删链接**，再 `git worktree remove`（**不加 `--force`**）。
- **事后必查**：`git status --porcelain | grep -c '^ D'` 必须为 0。
