## 二、观察到的偏差（Step 2）

用户原话（两段）：
> 「前端的元素选择按钮无法使用了，点击之后变成位置已记录」
> 「配置中心的所有子页面里面都有非常多的副标题，这些副标题像新手指南一样，暴露的非常多
> 开发专用的信息，而且它的文本链路非常长，这也就导致所对应的输入框长度变得异常的夸张，
> 整个页面的分布也极其不合理」

## 三、执行链追溯（Step 3）

### ① 元素选择按钮

```
用户点击悬浮按钮（pointerdown → pointerup）
  └─► onFabPointerDown: 起 window.setTimeout(160ms) 定时器
        └─► 到点 → dragRef.active = true（进入拖动态）
  └─► onFabPointerUp:
        若 d.active → saveFabPos() + setPosTip("位置已记住")   ← ★ 断点
        否则        → setActive(v => !v)  ← 切换选择模式
```

**判据缺陷**：拖动意图 = **按住时长**。普通点击只要按得稍慢（>160ms）或手抖 >4px，
`d.active` 即为 true ⇒ 落进拖动分支 ⇒ **永不切换选择模式**。

### ② 配置中心字段布局

```
SchemaField: <div className="set-field">   ← ★ 断点：set-field 已无 CSS 定义
  父容器: <div style={{display:flex, flexWrap:wrap, gap:12}}>
  └─► flex 项缺 flex-basis/min-width:0 → 按 max-content 定宽
        └─► 中文无空格 ⇒ 一行 hint = 一个不可断「单词」
              └─► max-content = 整条 hint 长度 ⇒ 字段极宽
                    └─► input width:100% 同步溢出 ⇒ 整页分布崩坏
```

**取证（git 历史）**：`global.css:851` 原文——
```css
.set-field { flex: 1 0 220px; min-width: 0; display:flex; flex-direction:column; gap:4px; … }
```
该文件于 `eec6fea`（v0.43.16「旧 CSS 体系下线」）被删除，而消费点未同步。

## 四、根本原因分析（Step 4）

1. **元素选择**：用**时长**推断**意图**——时长与「是否想拖动」无因果（慢点击天然冲突）。
2. **配置中心**：**CSS 体系迁移未同步扫消费点** —— 删 CSS 留 `className`（死类名），
   在 flex 容器下静默退化为 `max-content`；中文长句放大后果（撑破布局）。
3. **叠加（文案）**：三条冗余链路（页头 78 字 / 教学段落 / 124 条 schema hint，其中 8 条含
   内部实现细节）——用户偏好「保持简洁、删除冗余、勿暴露开发信息」。

**架构层观察（可迁移）**：两处同型 —— **「判据」与「目标」之间缺少因果链**：
① 用可观测代理（时长）代替真因（位移）；② 用样式类名代替真实布局约束（类名已无定义）。

## 五、修复方案

| 位置 | 改动 |
|---|---|
| `element-inspector.tsx` | 拖动判据 `DRAG_HOLD_MS=160` → `DRAG_MOVE_PX=4`（位移阈值）；`pointerdown` 立即 `setPointerCapture`；`pointerup` 无位移即切换模式 |
| `unified-config-widgets.tsx` | 字段布局内联化 `flex:1 1 240px; minWidth:0; maxWidth:100%`；hint 加 `overflowWrap:anywhere` |
| `settings-page.tsx` | 页头说明 78 字 → 一句 |
| `UnifiedConfigSection.tsx` | 「保存到/当前」教学段落压成一句 |
| `app_config_schema.py` | 8 条 hint 去 `BCC`/`hardcoded timeout=`/`socket`/`.env`/`/api/probe/run`/`ADR-007 D2`/`带账号 cookie` |
| `test_element_inspector_guards.py` | 判据从 `assertIn("DRAG_HOLD_MS")` 反转为 `assertIn("DRAG_MOVE_PX") + assertNotIn("DRAG_HOLD_MS")`（钉成负控） |

## 八、可迁移判据

1. **「单击/拖动/长按」复用一个控件时，时长不可作区分依据**（慢点击天然冲突）——
   用**位移阈值**。
2. **动作覆盖提示即缺陷信号**：用户点按钮，系统却弹「位置已记录」——提示与实际意图不符时，
   先怀疑判据，不要接受「它就是这样」。
3. **CSS 体系迁移必须同步扫「旧类名消费点」**：删 CSS 留 `className`，在 flex 容器下静默
   退化为 `max-content`（中文长句尤甚），**比样式缺失更严重**。判据：`getComputedStyle(el).flexBasis`。
4. **中文长句在 flex 项内是「不可断单词」**：`min-width:0` 是 flex 收窄的**必要条件**；
   缺它则 `width:100%` 的子元素会撑破容器。
5. **守卫测试可能固化缺陷**：本处守卫原断言 `assertIn("DRAG_HOLD_MS")` 恰好守护了**错误设计**；
   修正设计时必须**同步反转守卫判据**并留负控，否则「门禁变红」会阻止正确修复。
