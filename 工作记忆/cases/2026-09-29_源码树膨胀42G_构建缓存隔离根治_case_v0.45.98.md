# 案例：源码树膨胀 42G —— 构建缓存隔离根治（v0.45.98）

- **日期**：2026-09-29
- **分支**：design（环境 `C:\temp\dyautodm_design`）
- **类型**：架构/基础设施缺陷（非业务逻辑）
- **ADR**：`docs/adr/ADR-029-build-cache-outside-source-tree.md`
- **提交**：（见文末）

---

## 1. 现象与初始疑问

用户提问：源码树 `C:\Users\LOX\Desktop\DYchajian` 膨胀至 **42G**，
"我明明已经把部署路径和源码路径隔离了，为什么还这么大？"

## 2. 取证（实测，非推断）

```
DYchajian/                     42G
├── .git                       46M   （健康）
├── _ext_repos / LLM-Wiki      54M
└── DYAutoDM_v2/               40G   ← 唯一元凶
    └── src-tauri/target/      40G
        ├── debug/             33G
        │   ├── incremental/   24G   ← 166 个快照，每个 ~460M
        │   ├── deps/          5.2G
        │   ├── build/         2.7G
        │   └── _up_/          720M  ← Tauri 资源整包拷贝
        └── release/           6.0G
```

## 3. 根因（到源头）

**隔离没失效** —— 隔离的是**运行期数据**（数据根 `C:\temp\dyautodm_design`）。
`target/` 是 **cargo 编译期缓存**，cargo **默认就放在项目树内**，**这层从未被纳入隔离**。

| 累积源 | 机制 |
|---|---|
| `target/debug/incremental/` | 每次重编若 crate 指纹变化，**新建** ~460M 快照，**旧份从不回收** ⇒ 单调增长 |
| `target/*/_up_/` | Tauri `bundle.resources` 打包时整包拷贝资源（含 `vb_chromium` 425M） |
| `target/*/deps`、`build/` | cargo 中间产物 |

**决定性证据**：当日清空 `target/`（40G）后，另一次构建**立即重新生成 4.0G**
⇒ 证明是**结构性复发**，非一次性堆积。

## 4. 处置（架构改造，用户拍板）

| 组件 | 内容 |
|---|---|
| `src-tauri/.cargo/config.toml` | `[build] target-dir = "C:/temp/dyautodm_build/design"`（路径字面量**唯一**处） |
| `scripts/build_paths.py` | **新增** SSOT：`env → config.toml → 兜底树内` 解析 |
| `build_all.py` | `_env()` 显式注入 `CARGO_TARGET_DIR`；新增 `--prune-cache`（默认关） |
| `deploy.py` / `package_installer.py` / `verify_build.py` | 改读 `build_paths`（消除 5 处硬编码 target 路径） |
| `check_iron_rules.py` | **新增 R10**：源码树内存在 `target` 即 FAIL（防绕过脚本直接构建） |

**上游取证**（Open-Source Provenance）：[tauri#13654] 的 `resource_dir()` panic
**对本项目不适用** —— Rust 侧只用 `std::env::current_exe()`（全仓零 `resource_dir()`），
Python 侧 `resource_root()` 基于 `sys.executable`。

## 6. 教训

1. **"隔离"要明确边界**：隔离运行期数据 ≠ 隔离编译期缓存。凡"应位于树外的目录"须**逐类枚举**，
   否则会出现"以为隔离了、其实只隔离了一半"。
2. **单调增长类缺陷在源码里看不出来**：必须用**运行时体积实测**（Live-Instance）。
3. **路径硬编码散落 = 迁移必漏**：5 个脚本各写各的 target 路径，收敛到 SSOT 才可安全迁移。
4. **声明式铁律 = 空架子**：必须配机械门禁（R10）否则绕过脚本即复发。
