## 三、RCA：小助理账号「只读态」（本轮同轮抓出的真缺陷）

### 现象
`POST /api/messages/send`（account=尚进工伤小助理）→ **HTTP 200 但 `ok:false`**：

```
WS=create_conversation 响应缺少 create_conversation_v2_body
   message='unexepcted session length'
   resp_json={'cmd': 609, 'sequence_id': '10578', 'message': 'unexepcted session length', 'body': {}}
WP=页面无搜索框（可能未登录/未在 chat 页）
```

两次复测（换不同真实观众会话）→ **稳定复现**（`sequence_id` 10578 / 10173）。

### 判型（A/B 对照，同刻·同后端·同网络）

| 账号 | `dm` 写校验（`POST /api/accounts/{name}/check` → `probe_im_write`） | 判定 |
|---|---|---|
| 尚进工伤小助理 | `level=fail` · 「私信凭证不可写」· cmd 609 `unexepcted session length` | ❌ 只读态 |
| 四川工伤张老师 | `level=ok` · 「私信凭证可用（写校验通过）」· cmd 609 建会话被接受 | ✅ 可写 |

⇒ **账号级故障，非全局**。对照 `01:00` 该账号尚能真实发送（落库含真实文案），⇒ **10 小时内进入只读态**。

### 结论
`cmd 609 unexpected session length` = 服务端判定「web 会话只读」（**读会话 ✅ / 建会话 ❌**），属**凭证需重建**，非网络/非风控封锁、非直播间状态。

### 处置
对该账号执行 **【重新扫码】** 重建登录态（探针 `auto_fix_triggered=false`，需人工）。
