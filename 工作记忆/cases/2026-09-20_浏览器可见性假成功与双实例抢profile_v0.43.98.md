# 调试案例归档：指纹浏览器「只看得到弹窗/加载卡顿/扫码读不到回执」（v0.43.98）

**日期**：2026-09-20
**版本**：v0.43.98（design/better-douyin，运行实例 `C:\temp\dyautodm_design`）
**严重度**：fatal（浏览器观测态完全不可用 → 凭证无法更新 → 私信链路停摆）
**状态**：根因已定位并修复，实机验证通过

---

## 一、设计意图（Design-First）

| 入口 | 设计契约 |
|---|---|
| `POST /api/accounts/{name}/open-browser`（双击打开指纹浏览器） | 把**常驻 BCC 容器就地切为有头可见**；不另起实例、不抢 profile。用户应看到**真实登录态窗口** |
| 引擎校验 `verify_account(auto_fix=True, dm_loopback=True)` | 凭证有效 → dm 守护正常；失效 → 重捕凭证（同样不得破坏单实例） |

**用户追加拍板的边界契约（2026-09-19）**：
- 凭证有效 + 有任务在跑 → **禁止**打开有头浏览器；
- 凭证失效 → **所有任务暂停**，引导用户双击打开有头浏览器作观测态判断/恢复凭证；
- 有头观测**必须由同一个 BCC 容器完成**，绝不另起第二个 chromium。

## 二、观测偏差

1. 双击打开浏览器 → 只看到弹窗，**看不到浏览器页面**；
2. 引擎校验拉起的浏览器**加载异常、卡顿**；
3. 手机扫码授权后**读不到授权回执**，刷新一直转圈。

## 三、执行链追溯与根因（RCA）

### 根因 ①（主）：`set_visible` 的「只改窗口状态」路径与纯无头前提冲突，且截断了真正的重建
- `browser_daemon.py` 的 window 快路径（`Browser.setWindowBounds`）前提是「容器常驻**真有头+最小化**」（`7395c59`，09-13 引入）；
- `2bdea46`（09-14）把内核改为**纯 native headless** 后**前提作废，但 `set_visible` 从未同步**；
- 该分支命中后直接 `return`，**下方真正的「关 context → 重建有头」成为死代码**。

### 根因 ②：双实例抢同一 profile（用户问「为什么会出现两个实例」的答案）
- 「扫码/重捕」旧路径（`enrich_auth` → `login_grab_ticket`/`read_auth_from_profile`）**绕过统一入口** `browser_gate.ensure_browser`，自己 `launch_persistent_context(headless=False)`；
- 它启动前 `_quit_browser_daemon` **停掉 BCC**，而同一次 `verify_account` 的 dm 段紧接着 `ensure_daemons_for` **又拉 BCC** —— 两段分属不同模块、**中间无共享锁**；
- ⇒ 两个 chromium 重叠持有同一 profile。

### 根因 ③：`audit_standalone_launch` 只告警不阻断
源码自述：「先观测，收敛完残余路径后再收紧为阻断」——**一直没收紧**。

### 连带缺陷：注入脚本破坏原生函数身份
`CAP_*_HOOK_JS` 用普通函数替换 `window.fetch` / `XMLHttpRequest` / `WebSocket`，**未保留 name/length 与 WS 静态常量**（实测 `fetch.name` 由 `'fetch'` 变 `''`）→ 易被前端/风控的「原生函数篡改」探测命中。

## 四、实机证据（决定性）

| 实验 | 结果 |
|---|---|
| 浏览器本体能否加载抖音（真实指纹参数，headless/headed） | ✅ 均能出扫码登录页 + 二维码（**证伪「浏览器本身坏」**） |
| 注入开销：per-秒 `outerHTML.slice(0,4000)` | 首页 55.8ms（首帧 128ms）/ chat 页 5.6ms —— 有开销但**不是卡顿主因** |
| WS hook 每帧 base64（100KB） | 2.0ms —— 可忽略 |
| 关容器后立即/1.5s/3s 重开同 profile | ✅ 三次全成功（**只有"重叠"才炸**） |
| **两实例同时持同一 profile** | ❌ `TargetClosedError: Target page...has been closed`（**精确复现**） |
| **纯无头下 `setWindowBounds('normal')`** | 返回 **True**，但 **OS 可见窗口 = 0**（有头 = 1）→ **静默假成功** |

修复后对照（临时 profile）：旧路径 **0** 窗口 / 新路径 **1** 窗口 → PASS。
