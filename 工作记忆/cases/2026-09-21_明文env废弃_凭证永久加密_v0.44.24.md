# 案例 · 明文 .env 彻底废弃：凭证永久加密（v0.44.24）

> 日期：2026-09-21　分支：`design/better-douyin`　环境根：`C:\temp\dyautodm_design`
> 关联 ADR：`DYAutoDM_v2/docs/ADR-006_凭证永久加密_明文env废弃.md`
> 前置案例：`2026-09-21_凭证自锁根治_会话活性门禁_v0.44.23.md`

---

## 一、设计意图（回归设计理念）

会员体系是**确定形态**：凭证的唯一合法存储是 Fernet 加密的 `<env_path>.enc`。
「明文 `.env` 兼容分支」自始就是过渡态；会员体系定型后它必须消失，否则：

- 明文凭证存在落盘可能（安全失守）；
- 「文件是否存在」类判据在明文文件消失后**恒假**（功能假失败）。

## 二、当前状态偏差（实测）

| 项 | 实测 |
|---|---|
| members 空间明文 `.env` | **0 个** |
| members 空间 `.env.enc` | 2 个（张老师 / 尚进） |
| 环境根游离明文 `.env` | 无 |
| 代码中的明文分支 | 读 7 处 + 写 2 处（`is_member_env` 分支）、明文读写助手 2 个 |
| **静默漏洞** | `save_credential` 有一条绕过 `DY_ALLOW_PLAINTEXT_ENV` 的明文 `set_key` 路径 |

## 三、执行链（明文分支的形态）

```
调用方 → is_member_env(env_path) ? parse_env_dict(.enc) : dotenv_values(明文)
save_credential → is_member_env ? write_env_file(.enc) : set_key(明文)   ← 静默漏洞
各处存在性判据 → os.path.exists(env_path)  ← 会员空间内恒假（明文文件不存在）
```

## 四、根因

**明文兼容分支未随会员体系定型而收敛**，导致：
1. 写入侧仍有明文落盘路径（安全）；
2. 读取/存在性判据以明文路径为锚，在「只有 .enc」的现实下恒假（可用性）。

## 五、修复（v0.44.24，方案 A 硬废弃）

1. `member_ctx` 成为**唯一入口**：`write_env_file` 只写 `.enc`（主密钥不可用即抛 `MEM-007`）；
   `parse_env_dict/text` 只读 `.enc`（**不读明文**）；新增 `env_exists()`；`migrate_plain_envs` 废弃。
2. 删除 `DY_ALLOW_PLAINTEXT_ENV` 逃生口与写盘 fallthrough（失败报 `AUTH-054`）。
3. 9 个模块统一到 `member_ctx` / `env_exists`（见 ADR-006 变更表）。
4. `login_capture.snapshot_old_env` 一并修好「首次登录」误报（只认 `.enc`）。

## 六、语义后果（有意为之，勿当 bug）

- **未登录不允许凭证读写**：主密钥不可用 → 显式失败。这是「永久加密」的必然推论。
- **磁盘上出现明文 `.env` 会被拒绝读取**（不静默使用未加密凭证）——正是本决策要的语义。

## 七、验证

- 守卫 `backend/test_plaintext_env_deprecation.py` **6/6**；反向验证：恢复明文分支 → **红 2 项**，还原 → 绿。
- 全量回归 **460 项** = 基线 443 + 11（自锁）+ 6（本批）；唯一失败 `test_member_smoke` 为**存量**
  （`git stash` 本批改动后**同名、同行 87、同 `InvalidToken`** 失败；且该失败在会话起始交接卡已记录）。
- 全仓明文路径终扫：`set_key` / `dotenv_values(env_path)` / `load_dotenv(env_path)` **0 命中**（仅注释）。

## 八、坑（新增）

- **码号撞车**：`AUTH-041` 在注册表里已被「批量查昵称」占用（旧代码编号冲突），
  故「加密写盘失败」必须另用 `AUTH-054`；`MEM-005/006` 亦已被占用，改用 `MEM-007`。
  ⇒ 新增错误码前 `python -c "import errcode_data as E; print({c:E.ERRCODES[c] for c in ...})"` 逐条看含义，别只看编号空缺。
- **`is_member_env` 现在只回答「加密凭证是否存在」**：调用方不应再写
  `if is_member_env(...): 解密 else: dotenv` 的二分支（否则会员空间外仍可能走明文）。
