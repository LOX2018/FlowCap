# v0.43.85 — E1 选区导出 + E2 单条存图（seq 同口径契约）

**版本**: v0.43.85 · **日期**: 2026-09-18 · **Commit**: ac3f9e0 · **分支**: design/better-douyin

## 根因（比功能本身更重要的发现）

**前端 index ≠ 渲染端点 seq**。此前两处过滤口径不一致：

| 过滤条件 | 详情端点 `get_conversation` | 渲染端点 `fetch_range`（修复前） |
|---|---|---|
| `msg_type='50001'` 回执 | ✓ | ✓ |
| `msg_type='7' AND msg_id IS NULL` | ✓ | ✗ |
| 系统引导文案（对方回复你或互关之前/请礼貌发言/自觉遵守） | ✓ | ✗ |
| 裸 `[分享视频]` / `[未知媒体]%` | ✓ | ✓ |
| `iesdouyin.com/share/%` 脏链接 | ✓ | ✗ |

若直接把前端数组下标当 seq 传给 `/render/png`，含噪音的会话会**导出错条**（把没选的系统引导噪音画进长图、漏掉真实消息）。修法：`fetch_range` 采纳详情端点全部过滤条件——渲染侧顺带修掉"长图带噪音"的老缺陷，且排序口径本就一致（`created_at_us` 优先、`ts*1e6` 量级兜底），无需动。

## 设计取舍

- **seq 唯一来源 = 后端下发**：本地兜底消息（无 `mid_` 前缀 id）没有 seq → 不显示存图按钮、点击提示，绝不前端自行编号（否则必然错位）。
- **E2 用 hover 行尾小按钮**而非 hover 菜单弹层：与既有行尾「网页」通道角标同范式，实现轻。
- **选区导出复用既有渲染端点**（`start_seq/end_seq` 闭区间），后端零新端点。
