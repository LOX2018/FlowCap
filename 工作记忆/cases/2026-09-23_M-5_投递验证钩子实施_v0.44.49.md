# 案例 · M-5 投递验证钩子实施（v0.44.49）

> 日期：2026-09-23　提交：`c4b13f5`
> 来源：HC-07 §2.4

## 目标

在私信成功投递后向 `dm_messages` 写入 `[投递验证]` 标记，使探针 `probe_send_delivery` 的 `delivery_verified` 计数 ≥1，消除张老师 269 条已发无证据的 degraded 状态。

## 实施内容

| 文件 | 改动 |
|------|------|
| **新建** `backend/services/delivery_verify.py` | `mark_delivery_verified()` 工具函数：解析 statusCode/check_code → 条件满足则 INSERT `[投递验证]` 行 |
| `backend/core/dispatch.py` `_do_send()` | 回落直发成功分支（`if ok:` 内 `if not _routed:`）调 `mark_delivery_verified()` |
| `backend/services/dm_dispatch.py` `_send_one()` | 异步调度成功分支（`if ok:` 内）调 `mark_delivery_verified()` |

## 判定口径

- `statusCode == 0` **且** `check_code != 8610` → 写入 `[投递验证]` 标记
- `statusCode != 0` 或 `check_code == 8610` → 跳过写入（日志记录为 SEND-041/SEND-042）
- DB 写入异常 → 只打 warning 不抛异常（SEND-044），不阻断发送
