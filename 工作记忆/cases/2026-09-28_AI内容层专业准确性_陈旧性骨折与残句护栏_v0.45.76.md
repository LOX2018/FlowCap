# 案例：AI 内容层「专业准确性」缺陷 —— 陈旧性骨折答反 + 残句外发（v0.45.76）

- 日期：2026-09-28
- 关联：ADR-024、`services/ai_reply.py`、`services/pro_kb.py`（数据）
- 前序：ADR-021 D4（治「客服腔」，v0.45.68）· ADR-022（回复库向量提纯）

## 1. 起因（用户实测）

用户问：「陈旧性骨折还能认工伤吗，厂里不认」——AI 回 **「能认」**。
用户判定：**与专业知识完全相悖**（陈旧性骨折难以证明本次因果，实务中基本不予评定）。

## 2. 诊断（先查「喂进去的东西」，最后才看 prompt）

按 skill 零号判据，未先改 prompt，而是打印**真实载荷**：

- **配置正确**：agent `ag_88387f9ee4e34dc1`（两账号共用）→ merchant=唐律工伤团队、
  strict_level=rag、enabled=true、model=glm-5.2、max_tokens=1000、temperature=0.7。
  （⚠️ 我一度误读为「空」—— 因字段在**嵌套 `config`** 下；核实 `resolve_config`
  实现后订正，见 skill「读空值先怀疑字段名」。）
- **系统提示词不是客服腔源头**：该 prompt 已写明「专业顾问，不是客服／不磨叽／禁占位话」。
- **命中库**：81 条**全为 `auto`** 学习碎片（`湖北黄冈→好的`、`clw6083→好`、
  `江苏盐城→好的`、个案照搬），40 条仍可「命中即回」零 token 直发。
- **知识库（唯一事实来源）缺条**：`pro_kb` 6 条**无一条**讲「陈旧性骨折能否认定」。
- **出口护栏缺最小长度**：`validate_reply` 只有违禁词 + 最大长度 ⇒ 2 字残句直发。

**载荷实测（5 条真实咨询）**：
| 输出 | 形态 |
|---|---|
| 「腰椎骨折多评九级…以劳动能力鉴定结论为准。你在哪个省？」 | ✅ 好（agnes） |
| **「能认」** | 🔴 2 字残句（deepseek，agnes 超时降级后） |
| 「十级核心是这几笔…」 | ⚠️ 疑截断 |

## 3. RCA

- **根因**：知识覆盖缺口 ⇒ 模型无事实可锚，顺着「给判断」的提示**编出乐观答案**
  （陈旧性骨折「能认」= 与专业知识相悖）。属 skill 的「上下文装配源为空 → 编造」族。
- **放大器**：出口护栏无最小长度，残句「能认」直发客户。
- **诱因**：`agnes-2.5-flash` 两次 60s 超时，降级到 `deepseek-v4.1-flash` 后更差。

## 4. 修复（最小契约升级）

1. **补知识（根）**：pro_kb +2 条（经运行中后端 API 写入，不直写活库）：
   - 陈旧性骨折**基本不予认定** + 证据链要求 + **不承诺结果**；
   - 评残按**功能障碍**（GB/T 16180），**不按伤名对号入座**、不断言等级。
   依据《工伤保险条例》第 14/17/21/22 条。
2. **残句护栏**：`validate_reply` 增 `min_reply_len`（默认 5）。
3. **专业准确性护栏**：`_RE_ASSERTIVE` 拦绝对化断言（陈旧性骨折+肯定认定 / 等级断言）。

## 5. 验证（真机复验）

| 问题 | 修复前 | 修复后 |
|---|---|---|
| 陈旧性骨折还能认工伤吗 | 「能认」 | 「旧伤基本认不了，关键看是不是这次干活受的伤」 |
| 我腰椎骨折能定几级 | 「多评九级」 | 「几级不看骨折名字，看压缩程度和后期功能恢复，以鉴定为准」 |

- 门禁：`test_ai_reply_quality_guards` **6/6**（负控：残句/断言必须变红；
  正控：含「以认定结论为准」的正常分析**不得**被误伤）。
- 相关回归：`test_h31_ai_reply_safety` 9/9、`test_reply_purify*` 全绿。
- 前端 `npm run build` ✓（`min_reply_len` 进 AI 页）。
- 实库回读：pro_kb **6 → 8** 条（经 `/api/ai/prokb` 只读回读确认）。

## 6. 未覆盖（诚实标注）

1. `sem_enabled=False` ⇒ pro_kb 走「时间衰减取前 5」**非相关性**；实测
   「十级能赔多少 → 没法一口报」（KB 有「十级 7 个月」却含糊）。**需用户定夺**是否开语义。
2. 命中库 81 条 auto 碎片（40 条生效）仍是最高优先级风险面；存量清理**需用户拍板**。
3. 断言护栏是**形态匹配**，覆盖有限（防绊，非根治）。
