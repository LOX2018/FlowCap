## 一、回归设计意图（Step 1）

- **发送链设计契约**：`services/send_response.delivery_verdict()` 是投递判定的**唯一解析器**；
  `dm_dispatch.AccountQuota` 是发送频率的**唯一仲裁点**（最小间隔 + 冷暖纪）。
- **AI 获客设计契约**：Agent 管「回什么」（prompt/知识库），strict_level=rag 时注入
  专业库(pro_kb)作事实来源、命中库(reply_kb)作「命中即回」。
- **NFR**：发送频率需**分钟级可控**（风控面），且失败可归因。

## 二、实测偏差（Step 2）

| 偏差 | 证据 |
|---|---|
| 风控类失败**不触发冷静期** | `on_result` 只按关键字(FREQUENT/RATE/TOO_...)匹配；抖音 `{"decision":"KICK"}` 经 client_im 生成的文案「抖音拒绝发送：KICK（风控/限流…）」**不含**任一关键字 ⇒ 漏冷静 |
| 失败类型是**自由文本** | `/send` 回 `{"ok":false,"error":"<可读串>"}`，dm_dispatch 反推；verdict 的 `state/check_code` 未透传 |
| **无分钟级全量管控** | `stranger_per_minute` 仅限陌生人首发；熟客/AI 回复不受分钟约束；无账号级分钟窗 |
| AI 不专业 | **实库 `ai_pro_kb` 不存在**（`GET /api/ai/prokb`→`items:[]`）⇒ RAG 注入「（知识库暂无条目）」 |
| AI 像客服/墨迹 | 张老师会话连发 4 次占位兜底「图我看到了哈，稍等我看看再回你」；命中库 94 条全为 auto 学习碎片（"可以的"/"好的"），且**最高优先级命中即回** |
| AI 优柔寡断 | Agent 自定义 prompt 强制"严格分步"，客户已给全信息仍反复问部位/恢复 |

## 三、链路溯源（Step 3）

`DouyinAPI.send_msg`(client_im) 持有服务端响应 → `delivery_verdict` 判定 → 3 元组 `(ok, detail, verdict)`
→ `recv_daemon./send`/`/send_by_uid` 归一为 `{"ok":false,"error":...}` → `dm_dispatch._send_one`
读 JSON → `AccountQuota.on_result(ok, detail)` 关键字判冷静。**类型信息在每一步被降维成文本**。

## 四、RCA（Step 4）

- **回执**：判定依据被"字符串化"，任何文案改动即静默失效（契约漂移）。
- **AI 不专业**：链路通、但**上下文装配源为空**（pro_kb 未建）——属「配了走不通/静默空」族，
  与 skill 铁律 §十六.5「AI 不智能先查注入链路，别先改 prompt」一致。

## 五、修复（最小契约升级）

1. **结构化失败类型**：`send_response` 新增 `KIND_*` 枚举 + `failure_kind()` + `kind_is_cooldown()`；
   `delivery_verdict` 输出补 `error_kind`；`client_im`（含 HTTP/JSON/无证据三分支）挂 `error_kind`；
   `recv_daemon` 透传；`dm_dispatch._send_one` 读回并透传 `on_result(ok, detail, kind)`。
2. **冷静期补全**：`on_result` 优先按 `kind in COOLDOWN_KINDS{rate_limited,risk_control}` 触发；
   无 kind 时回落关键字（**兜底表扩入 KICK/INVALID_REQUEST/RISK/风控**）。默认冷静 **600s=10min**，连续翻倍封顶 1h。
3. **分钟级管控**：`AccountQuota` 增 `_minute_sends` 滑窗 + `can_send(min_interval, per_minute)`；
   新配置 `send.per_minute_limit`（默认 3，env `DY_SEND_PER_MINUTE`，0=关闭）；`_LAZY_MAP` 增 `PER_MINUTE_LIMIT`。
   **手动发送豁免**（`source=='manual'` 不 check），但**仍计入**分钟窗（门禁不拦用户显式操作铁律 + 保护账号）。
4. **AI 治标**：张老师 Agent prompt 重写为「工伤理赔顾问」（去"客服"、禁占位话、不重复问、价值交换式留资）；
   补 6 条 grounded 专业库（《工伤保险条例》第37/33/62/64条，出处=国家税务总局政策法规库）；
   `reply_kb` 加**质量门槛**（写入侧不再学占位/短句，匹配侧脏 auto 条目失效**不删除**、可逆）。
