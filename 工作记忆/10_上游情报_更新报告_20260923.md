## 四、技术备注

1. **API 限流问题**：第一轮匿名 GitHub API 调用在 11 项目 × 3 请求后触发限流（60 req/h/IP）。第二轮使用已失效的 token 返回 Not Found。最终通过网页 commit 页补充获取详细信息。
2. **track_upstream.py 缺陷**：该脚本使用 `/repos` 端点，不返回 `head_sha`（只返回默认分支名），导致 `prev_sha` 永远为空 → 恒报 🆕 而非 🔔。已通过手动抓取 commit 页修正，但应推动脚本修复：改用 `/repos/{owner}/{repo}/commits/{default_branch}` 取 sha。
3. **openbrowser 异常**：该仓库 API 返回 `null`（可能已私有化/删除），但 commit 页仍可访问——`lyu0805/OpenBrowser` 实际有更新，需手动追踪。
