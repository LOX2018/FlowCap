# 2026-09-10 晚：Agent 分类 + 作用域 + 调度 Agent（v0.39.0 内）

## 用户拍板的最终语义
- **Agent 分两类**（`kind` 字段）：`dm`=私信 Agent（可多个）、`dispatch`=调度 Agent（仅一个默认 `ag_dispatch_default`，IM Bot 用）。
- **作用域 scopes**（私信 Agent 属性，多选）：`dm`私信中心 / `live`直播监听 / `crawl`视频采集——决定 AI 智能回复注入哪些模块。**放弃**"账号绑定=作用域"方案；账号绑定只决定"用哪个 Agent"。
- **调度 Agent = IM Bot 权限方案**：permissions 控制它能对项目做什么（query_status / create_crawl_task / create_live_task / stop_task / update_kb 默认开（后三项需确认）；create_agent / recapture 默认关；管理提供商**不开放，纯通知**——用户原话）。
- 直播监听/视频采集接入 AI 后**纯 AI 生成**（非模板润色）。
