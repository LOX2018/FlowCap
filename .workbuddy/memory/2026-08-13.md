# 2026-08-13

## 账号管理卡片样式/缩放修复
- 修复文件：`DY_Spider_base/web/index.html`、`DY_Spider_base/web/pages/accounts.js`，同步 `_compiled.html`
- 问题：账号卡片 4 个板块（守护服务/上次运行日志/引擎校验/关联指纹浏览器）容器样式不统一，且 2x2 grid 在非全屏/窄宽时因内容最小宽度导致列宽从 5:5 变为 7:3。
- 改动：
  - `.acct-body` 改为 `grid-template-columns: minmax(0, 1fr) minmax(0, 1fr)`，强制两列等宽。
  - `.acct-section` 增加 `min-width: 0; overflow: hidden`，防止内容撑开列宽。
  - 用 `nth-child` 为 4 个 section 统一网格分隔线（右/下边框），移动端堆叠时仅保留底部边框。
  - 移动端媒体查询增加 `grid-column: auto !important; grid-row: auto !important;`，重置内联 grid 定位，避免 section 仍按 2x2 定位导致堆叠异常。
  - `accounts.js` 移除首个 section 的内联 `borderBottom`，统一由 CSS 控制边框。
- 验证：在 `screenshots/` 生成 test-1200/900/700/narrow 等截图，确认宽屏两列等宽、窄屏正确堆叠、720px 卡片强启双列仍保持 5:5。
